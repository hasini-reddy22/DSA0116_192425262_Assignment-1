## Compile and run
Open a terminal in the required task folder and run:

```bash
g++ -std=c++17 -Wall -Wextra Task06.cpp -o Task06
./Task06
```

On Windows PowerShell, run the executable as:

```powershell
.\Task06.exe
```

Replace `Task06` with the relevant task number. The source files use standard C++17.
